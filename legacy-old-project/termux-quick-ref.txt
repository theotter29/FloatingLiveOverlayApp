🚀 QUICK START (Copy-Paste)
═══════════════════════════════════════════════════════════════

1. Setup awal (PERTAMA KALI SAJA):
─────────────────────────────────────
pkg update && pkg upgrade -y
pkg install nodejs-lts
mkdir -p ~/live-overlay-server
cd ~/live-overlay-server
npm init -y
npm install express socket.io axios cors dotenv

2. Copy LiveServer.js ke folder ~/live-overlay-server
   (Download atau paste file)

3. Run server:
─────────────────────────────────────
node LiveServer.js

4. Check IP (dari terminal baru):
─────────────────────────────────────
hostname -I

5. Dari device lain, test:
─────────────────────────────────────
curl http://192.168.x.x:3000/health

🐛 COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════

ERROR 1: "npm: command not found"
──────────────────────────────────
FIX:  pkg install nodejs-lts
      node --version

ERROR 2: "Cannot find module 'express'"
──────────────────────────────────────
CAUSE: Belum install dependencies
FIX:   cd ~/live-overlay-server
      npm install express socket.io axios cors

ERROR 3: "EADDRINUSE: address already in use :::3000"
──────────────────────────────────────────────────
CAUSE: Port 3000 sudah dipakai
FIX:   1. Kill process lama:
          netstat -tuln | grep 3000
          kill <PID>
       2. Atau ganti port di .env:
          PORT=3001

ERROR 4: "LiveServer.js: command not found"
───────────────────────────────────────────
CAUSE: File tidak ada atau path salah
FIX:   1. Check file ada:
          ls -la LiveServer.js
       2. Pastikan di folder yang benar:
          pwd
          cd ~/live-overlay-server

ERROR 5: "connect ECONNREFUSED 127.0.0.1:3000"
──────────────────────────────────────────────
CAUSE: Server tidak running
FIX:   1. Buka terminal baru
       2. node LiveServer.js
       3. Check tidak ada error

ERROR 6: Device tidak bisa connect ke server
───────────────────────────────────────────
CAUSE: IP salah atau firewall
FIX:   1. Check IP:
          hostname -I
       2. Update di React Native app:
          serverURL = 'http://192.168.x.x:3000'
       3. Pastikan device & phone satu WiFi
       4. Disable firewall (temporary untuk testing)

🔥 USEFUL COMMANDS FOR SERVER
═══════════════════════════════════════════════════════════════

RUN SERVER & KEEP RUNNING:
──────────────────────────
node LiveServer.js              → Run (Ctrl+C to stop)
nohup node LiveServer.js &      → Run & detach
nohup node LiveServer.js > server.log 2>&1 &  → Run with logging

MONITOR LOGS:
─────────────
tail -f server.log              → Watch logs real-time
tail -20 server.log             → Last 20 lines
cat server.log | grep ERROR     → Search errors
clear && node LiveServer.js      → Clear & run

KEEP RUNNING SAAT SCREEN OFF:
──────────────────────────────
pkg install termux-wake-lock
termux-wake-lock node LiveServer.js

USE SCREEN SESSION (RECOMMENDED):
──────────────────────────────────
pkg install screen
screen -S live-server           → Create session
node LiveServer.js              → Run
Ctrl+A, D                       → Detach (keep running)
screen -r live-server           → Reattach
screen -ls                      → List sessions

TEST SERVER:
─────────────
curl http://localhost:3000/health    → From same phone
curl http://192.168.x.x:3000/health  → From other device
curl http://192.168.x.x:3000/api/broadcasts  → List broadcasts

💡 PRO TIPS
═══════════════════════════════════════════════════════════════

1. Keep Termux running:
   - Don't swipe away from Termux
   - Lock phone with screen on
   - Or use termux-wake-lock

2. Multiple terminals:
   - Press Volume Up + N for new session
   - Useful for monitoring while running server

3. Faster development:
   - Use "npm install" instead of "node LiveServer.js"
   - Create alias in ~/.bashrc for quick commands
   - Backup .env and LiveServer.js

4. Save bandwidth:
   - Update only when needed (pkg update)
   - Install minimal packages

5. Debugging:
   - Always check server.log
   - Use curl to test endpoints
   - Monitor with "top" while running

6. Remote access:
   - Use SSH: pkg install openssh
   - Then access from laptop/PC
   - sshd to start SSH server
